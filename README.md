# Food Ordering Management System

A simple Food Ordering Management System developed using Core Python.

## Features

- Owner can add, delete, and view restaurants.
- Owner can manage food items and view orders.
- Users can browse restaurants and view the food menu.
- Users can add food items to cart and place orders.
- Users can track orders and view order history.

## Technologies Used

Python

## Project Purpose

This project was created to practice Core Python concepts by developing a simple real-world food ordering application.
